# PlayStation 1 system theme assets

## Original 32-bit-inspired hardware assets

- Files: `Images/ps1-inspired-crt-frame.png`,
  `Images/ps1-inspired-console-controllers.png`
- Creation: generated from original, brand-neutral prompts with OpenAI image generation;
  no external reference images were used.
- Design: the artwork intentionally recalls a first-generation European 32-bit disc
  console, its wired dual-analog controllers, and a late-1990s CRT while omitting
  product logos, lettering, button symbols, characters, and game artwork.
- License: distributed as part of Retromind under GPL-3.0-only, to the extent copyright
  applies.

All remaining visual elements are drawn directly in Avalonia XAML.
