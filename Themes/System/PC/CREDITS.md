# PC Games system theme assets

## Modern PC hardware assets

- Files: `Images/pc-modern-monitor-frame.png`, `Images/pc-modern-tower.png`,
  `Images/pc-modern-keyboard-mouse.png`
- Creation: generated from original, brand-neutral prompts with OpenAI image generation;
  no external reference images were used.
- Modification: flat chroma-key backgrounds and the monitor screen contents were removed
  locally; transparent borders were trimmed for theme distribution.
- License: distributed as part of Retromind under GPL-3.0-only, to the extent copyright
  applies.

All remaining visual elements are drawn directly in Avalonia XAML.
