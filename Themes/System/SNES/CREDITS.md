# SNES system theme assets

## Original 16-bit-inspired hardware assets

- Files: `Images/snes-inspired-crt-frame.png`,
  `Images/snes-inspired-console-controllers.png`
- Creation: generated with OpenAI image generation. The monitor was created from an
  original brand-neutral prompt.
- Console geometry reference: [`Wikipedia SNES PAL.jpg`](https://commons.wikimedia.org/wiki/File:Wikipedia_SNES_PAL.jpg)
  by JCD1981NL, licensed under
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The photograph was used as
  a reference for the European/PAL console controls. The generated render omits the
  photograph's background, product lettering, logos, and colored emblem; the reference
  photograph itself is not included in the distributed theme asset.
- Design: the brand-free artwork is intentionally recognizable as European/PAL SNES-era
  hardware while omitting Nintendo logos, product lettering, characters, and game artwork.
  The system name is used only to identify the matching Retromind system theme.
- Modification: flat chroma-key backgrounds and the monitor screen contents were removed
  locally for transparent theme overlays.
- License: distributed as part of Retromind under GPL-3.0-only, to the extent copyright
  applies.

All remaining visual elements are drawn directly in Avalonia XAML.
