# Nintendo Game Boy Advance system theme assets

## Original handheld-inspired hardware asset

- File: `Images/gba-inspired-handheld-frame.png`
- Creation: generated with OpenAI's built-in image generation tool from original,
  brand-neutral prompts. A user-supplied internet image was used during the final edit
  solely as a reference for the shape and placement of the Start/Select-style controls;
  the reference image itself is not included in Retromind.
- Design: the artwork intentionally recalls an early-2000s horizontal 32-bit handheld
  while omitting manufacturer logos, product lettering, button symbols, characters, and
  game artwork. The background and screen opening use PNG transparency.
- License: distributed as part of Retromind under GPL-3.0-only, to the extent copyright
  applies.

All remaining visual elements and the localized game count are drawn in Avalonia XAML.
The system logo and description come from the user's library node.

## Generation prompts

The original generation requested a polished, brand-neutral, front-facing horizontal
handheld with a translucent indigo shell, central 3:2 screen opening, directional pad,
two face buttons, start/select controls, shoulder-button hints, and speaker grille. It
required a transparent background and screen aperture, with no logos, readable lettering,
characters, cartridges, or watermark.

A focused edit retained the device geometry, colors, controls, lighting, proportions, and
framing while converting only the outside background and the complete inner display area
to genuine PNG alpha transparency. The opaque screen bezel and hardware were preserved.
