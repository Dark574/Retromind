# PlayStation 2 system theme assets

## Original early-2000s-inspired hardware asset

- File: `Images/ps2-inspired-console-controller.png`
- Creation: generated with OpenAI's built-in image generation tool from an original,
  brand-neutral prompt. A user-supplied photograph of an original console was used only
  as a loose reference for the upright console, blue stand, and foreground-controller
  composition; the photograph itself is not included in Retromind.
- Design: the artwork depicts a fictional matte-black, vertically oriented console with
  layered cooling ribs, a translucent blue stand, and one wired dual-analog controller.
  It intentionally omits manufacturer logos, product lettering, badges, button symbols,
  characters, and game artwork. The outside background uses PNG alpha.
- License: distributed as part of Retromind under GPL-3.0-only, to the extent copyright
  applies.

All remaining visual elements and the localized game count are drawn in Avalonia XAML.
The system logo and description come from the user's library node.

## Generation prompt

> Create a polished transparent-background hardware overlay for a desktop game-library
> system theme. Use the attached early-2000s console product photo only as a loose
> reference for the overall composition: one tall upright black console behind one wired
> dual-analog controller, with a translucent electric-blue vertical stand. Do not copy
> any branding, product markings, proprietary logos, exact button symbols, or text from
> the reference.
>
> A wholly brand-neutral, fictional early-2000s home game console. The console is a tall
> matte-black monolith with layered horizontal cooling ribs and subtly offset rectangular
> tiers, standing vertically in a translucent cobalt-blue base. Give it enough distinct
> geometry to read as an original fictional device rather than an exact commercial
> product. One black wired controller lies in the foreground, with two analog sticks, a
> directional pad, shoulder controls, and four identical plain circular face buttons. The
> cable curves naturally back toward the console.
>
> Landscape 3:2 asset, isolated product render. Console occupies the rear-right and rises
> almost to the top; controller occupies the lower-left/center foreground. Show the full
> silhouettes with comfortable transparent padding on every edge. Three-quarter front
> view, similar visual balance to the reference but not a pixel-for-pixel match.
>
> High-end realistic 3D product visualization, restrained early-2000s industrial design.
> Matte charcoal plastic, fine ribbed texture, subtle cobalt-blue edge light and
> translucent blue stand. Neutral soft studio key light, believable soft contact shadows
> contained within the isolated object grouping. Crisp edges at theme-overlay scale.
>
> True transparent alpha background. No floor, no room, no backdrop, no vignette, no
> opaque or semi-opaque rectangle behind the objects.
>
> Absolutely no Sony logo, no PlayStation logo, no PS or PS2 lettering, no words, no
> letters, no numbers, no trademarks, no badges, no emblems, no watermark. No
> triangle/circle/cross/square icon set and no colored face-button symbols. Do not add a
> television, screen, game artwork, disc, packaging, extra controllers, or hands.
